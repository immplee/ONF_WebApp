# ONF_WebApp — Ownify 학생 웹앱 (액자)

학생이 여는 **하나의 주소**. 구글 사이트를 대신한다.

```
index.html   액자 한 장 — 토큰 기억 · iframe 띄우기 · 키보드 재기
hw.html      과제      (준비 중)
dict.html    발음기호  (준비 중)
assets/
  onf-frame.js  액자 공통 — 토큰 기억 · 키보드 재기 · 앱 화면에 붙이기
  onf-api.js    GAS 배포 주소 (⛔ 명부를 여기 두지 마라 — 공개 저장소다)
  onf-ui.css    브랜드 색 · 공통 골격
tools/
  roster-sync.py  노션(정본) → ONF_학생명부 시트 한 방향 동기화
```

## 왜 액자가 필요한가

1. **구글 배너를 가린다.** 앱스스크립트 웹앱을 최상위 창으로 열면 위에 "이 애플리케이션은
   Google Apps Script 사용자가 만들었습니다" 띠가 뜬다(모바일에서 화면 세로의 21%).
   iframe 안에서는 안 뜬다 — 그래서 원래 구글 사이트에 심어 썼다.
2. **자동화된다.** 사이트는 학생마다 손으로 만들고 게시해야 했다(API 없음).
   액자는 **한 장**이고, 학생·교재가 늘어도 늘어나는 건 명부 시트의 줄뿐이다.
3. **키보드를 잰다.** 앱은 iframe 두 겹 안이라 `visualViewport` 로 키보드를 못 본다(MDN).
   최상위 창인 액자가 재서 `postMessage` 로 내려준다. 구글 사이트로는 못 하는 일이다.

## 주소

```
/?t=<토큰>            홈 (GAS 가 그린다 — 이름 + 내 교재 목록)
/?t=…&diag=1          계측기(키보드 숫자) 표시
```

교재로 넘어가는 링크는 **홈 화면(GAS)** 이 그린다. 액자는 주소에 `fileId`·`sheetName` 이
있으면 그대로 넘겨주기만 한다.

⛔ **화면을 액자에서 그리려 하지 마라.** 액자에서 구글을 `fetch` 하면 CORS 로 전부 막힌다
(2026-08-06 실기기 크롬 실측: GET·POST text/plain·POST json·no-cors·JSONP 5가지 모두 차단,
`OPTIONS` 는 405, 응답에 `Access-Control-Allow-Origin` 자체가 없음).

토큰은 처음 한 번 주소로 받고 이 도메인에 저장한다. 다음부턴 주소 없이도 열린다.

## 손대기 전에

⛔ `assets/onf-frame.js` 의 숫자와 순서는 **실기기에서 하나씩 깨져 가며** 정해진 값이다.
고치기 전에 반드시 읽을 것: `ONF_Archive/웹-앱/ONF_공유웹앱-모바일-입력창.md` 의
**재발 방지 체크리스트 B1~B7**. 그 표의 전 항목에 "왜 안 깨지는지" 답하고 배포한다.

⛔ 학생 토큰·명부·개인정보는 **이 저장소에 넣지 않는다.** 시트에 있고 주소로만 전달된다.
